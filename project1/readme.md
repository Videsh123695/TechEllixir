# TECHELLIXIR - Employee Attrition Prediction System

A beginner-friendly **Data Science + Machine Learning** project that predicts whether an employee is likely to leave the organization.

## 🚀 Features
- Data Cleaning & EDA
- Feature Selection
- Multiple ML Models (Random Forest, Logistic Regression, SVM)
- Best Model: **Random Forest (~87% Accuracy)**
- Real-time Prediction using Streamlit Web App
